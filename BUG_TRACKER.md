### [2026-06-01] Модуль "Уведомления/Объявления" временно отключён

**Статус:** Отключён / Требует переработки

**Причина:** Оптимизация интерфейса. Модуль рассылки уведомлений (таблица `announcements`) отключён для упрощения навигации и снижения количества запросов к БД.

**Что сделано:**
- Компонент `AdminAnnouncements` на дашборде администратора скрыт из интерфейса
- Вызов `loadSentMessages` удалён из `useEffect` на `AdminDashboard`
- Светло-синий блок объявлений 🔔 на экране сотрудника скрыт
- Запрос `loadAnnouncement` отключён в `useEffect` на `StaffDashboard`
- Функции и стейты закомментированы (код не удалён)

**План исправления:**
1. Переработать архитектуру уведомлений
2. Вернуть модуль в интерфейс после рефакторинга

### [2026-06-01] Модуль "Склад МЦ" временно отключён

**Статус:** Отключён / Требует переработки

**Причина:** Критические проблемы с производительностью. Тяжёлые запросы к Supabase (таблица `warehouse_stock`) при загрузке дашбордов администратора и сотрудников, отсутствие кэширования, неоптимальная архитектура инпутов.

**Что сделано:**
- Компонент `WarehouseStock` на дашборде администратора скрыт из интерфейса
- Вызов `loadWarehouseStock` удалён из `useEffect` на `AdminDashboard`
- Кнопка/карточка "Списание МЦ" и модальное окно на `StaffDashboard` скрыты
- Функции и стейты закомментированы (код не удалён)

**План исправления:**
1. Переработать архитектуру — перейти на динамические материальные ценности (МЦ)
2. Оптимизировать инпуты (debounce, отложенная запись)
3. Добавить кэширование на клиенте
4. Вернуть модуль в интерфейс после рефакторинга
